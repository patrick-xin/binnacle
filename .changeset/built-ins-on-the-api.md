An author can read how many lines a Place shows with `binnacle.linesShown(place)`, where the Focus was last moved with `binnacle.focusMovedLast()`, read the editor's keys with `binnacle.keysOf('tui.select.up')`, and build a composer of their own from the exported `Editor`, `EditorTheme` and `CURSOR_MARKER`. Each built-in now uses only what an author can import.
