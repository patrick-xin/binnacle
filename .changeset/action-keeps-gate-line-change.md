An action set by another's id keeps what it does not name. With no `enabled`, it is enabled while the action it hides is, and with no `run`, it runs that action. So `binnacle.action('commands.list.pick', { run: () => binnacle.run('composer.send') })` takes enter only while the offer draws. An action's `place` can be a function of the Places of the action it hides: `binnacle.action('commands.list.up', { place: (places) => [...places, 'commands.search'] })`. A Line calls `change(text)` after each key of the person's that changes its text.
