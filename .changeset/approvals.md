'binnacle': patch
---

A person allows or rejects a tool that needs an approval, by key or click. A Request takes the composer's Place — the tool's name, why it asks, the call's arguments and the Choices "Allow once" and "Reject" — and enter picks the marked Choice, up and down move the mark, esc rejects, and a click on a Choice picks it. A second Request waits until the first is answered; a withdrawn Request is answered cancelled; when the plugin unloads, each Request that still stands is answered unavailable, so the tool fails closed. The row is `binnacle-approvals`.
