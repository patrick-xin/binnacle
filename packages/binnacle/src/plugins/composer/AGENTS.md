# plugins/composer

The Composer: where a person types a line under the transcript and sends it. It holds the `binnacle` service, to place binnacle's composer and to send a line or run it as one of dsh's commands through an author's grants; the editor is pi-tui's, and the commands dsh's.

- `index.ts` — the plugin: places the composer, and sends each submitted line, or runs it when it names one of dsh's commands.
